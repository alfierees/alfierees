### 🚀 Featured projects

**⚽ OddsLab: Premier League match outcome model**
Classification model trained on 24 seasons (9,120 matches) of Premier League data, built on 17 form features plus vig-normalised bookmaker probabilities, evaluated with strict time-ordered splits.
- Held-out accuracy **56.7%**, level with bookmakers (56.4%) and well clear of the always-home baseline (43.5%)
- Model weights exported from scikit-learn to plain JS so the predictor runs live in the browser
- `Python` `scikit-learn` `pandas` `JavaScript`

**🚨 [Under Fire](https://github.com/alfierees/under-fire): six years of rocket alerts in Israel, visualised** · [live site](https://under-fire.org)
Public-interest data journalism project covering 160,000+ alerts since January 2020. No commentary, only patterns and clear sourcing.
- Python pipeline compresses 54MB of raw alerts into nine aggregates (~500KB) for a fully static site
- Replaced per-alert geographic attribution (67% agreement) with salvo clustering and barrage-day detection (**93.1%**)
- Scheduled job refreshes, deduplicates and re-attributes data every 30 minutes
- `Python` `D3.js` `Leaflet` `GitHub Actions`

**🎙️ LocalFlow: private, on-device dictation for macOS** · [repo](https://github.com/alfierees/local-flow)
